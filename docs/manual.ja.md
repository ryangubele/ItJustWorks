# It Just Works™ の使い方

## 何をするか

Skyrim は会話、カットシーン、その他のスクリプト付きの場面に *シーン* を使います。ときどきシーンが終わらないことがあります。それは後から来るシーンを静かに塞ぐことがあります - クエストが進まないのに、エラーもクラッシュもない、という状態です。この MOD は、いま入っているシーンを見張り、長く居すぎたら知らせ、それが何かを見せ、詰まっているなら止められるようにします。

**短い版：** 既定のまま遊び続けてください。通知が来たら **Mod Configuration Menu > It Just Works** を開きます。

他 MOD のレコードを編集せず、パッチも不要なので、コンテンツスタックに対するロードオーダーの位置は関係ありません。あなたが停止を指示しない限り、シーンを変更することはありません。

必要なのは **[SKSE64](https://skse.silverlock.org/)**、**[MCM Helper](https://www.nexusmods.com/skyrimspecialedition/mods/53000)**、**[powerofthree's Papyrus Extender](https://www.nexusmods.com/skyrimspecialedition/mods/22854)**、そして **[powerofthree's Tweaks](https://www.nexusmods.com/skyrimspecialedition/mods/51073)**（ID 番号ではなく名前を出したい場合は `Load EditorIDs = true`）です。導入メモは [MOD ページ](https://www.nexusmods.com/skyrimspecialedition/mods/185927) にあります。

メニューは 5 ページです：**シーン**、**監視**、**設定**、**診断**、**アンインストール**。

## シーン

### いま何にいるか

現在のシーンの表示、または **なし**。メニューを開くと更新されます。

- **シーン内の時間** - このセッションでこのシーンにどれくらいいるかのおおよそ（実時間）。
- **シーン** - 名前が使えるときは名前、そうでなければ ID 番号。
- **Form ID** - 生の ID。常に表示されます。コンソールやバグ報告に便利。
- **所属クエスト** - そのシーンが属するクエスト。

### シーンを停止

シーンが詰まっていると思うなら、これで終わらせます。

1. **シーンを停止** を一度押す - アームされたことを一行で確認します。
2. もう一度押すとキャンセル、メニューを閉じると停止します。

詰まっていると思うシーンだけ止めてください。正常なシーンを止めると壊れることがあります。詰まったシーンを止めると、ゲームが追いつくあいだに遅延イベントが短く噴き出すことが（まれに）あります。

**更新** はメニューを閉じずに現在のシーンを読み直します。バニラの Skyrim ではメニュー中にゲームが一時停止するため、**更新** はあまり役に立たないでしょう。[Souls](https://www.nexusmods.com/skyrimspecialedition/mods/27859) のようなアンポーズ MOD を使っているなら、メニューを開き直さずに読み直せます。

### 最近のシーン

直近 10 シーン。新しいものが先。おおよその長さ付き。

## 監視

あなたに代わって見張ります。

- **警告するまでの時間** - シーンが通知を出すまでにどれだけ動けるか。既定 **6** 分。**0** = 通知しない。  
  ゲームにはシーンが詰まったと示す仕組みがなく、シーンがどれくらい続くべきかを教えてくれる仕組みもありません。そこでしきい値を決めて通知します。ゲーム内時間と実時間を組み合わせ、「実際にプレイしていた実時間」をおおよそ表せるようにすることで、この設定が直感的になるようにしています。
- **確認間隔** - 確認と確認のあいだの秒数。既定 **30**。**0** = 監視をオフ。
- **繰り返し通知** - 既定でオフ。シーンごとに 1 回だけ通知します。オンにすると、しきい値を超えている間、通知を続けます。
- **繰り返し間隔** - **繰り返し通知** がオンのときだけ使われる、通知と通知のあいだの分数。既定 **5**。

通知は角に出る 2 行です。例：

> シーンが他を妨害中 ~6m  
> See? It Just Works!

既定ではシーンごとに 1 回、そのシーンを出るか変わるまでです。見逃した？ メニューを開いてください - 表示はいま何にいて、どれくらいかを示し続けます。MOD はシーンを自動では止めません。それには **シーン** ページの **シーンを停止** を使ってください。

**監視** は、メニューが世界を一時停止する（バニラ）か、動かし続ける（[Souls](https://www.nexusmods.com/skyrimspecialedition/mods/27859) のようなアンポーズ環境）かにかかわらず同じように動作します - 通知は、そのシーンがしばらく動いているという意味でしかありません。

## 設定

- **有効** - 既定でオン。オフにすると、アンインストールせずに MOD を棚上げできます。
- **遊び心** - 既定でオン。通知は軽い調子を保ちます。オフにすると素っ気ない文言になります。変わるのは文言だけで、MOD の動作は変わりません。
- **通知の言語** - MOD 自身の隅の通知に使う言語。既定のメニュー言語を選ぶと、インストーラがこれを初期設定できます。このページでいつでも変更できます。既定かつフォールバックは英語で、ゲームの言語設定とは無関係です。
- **現在のシーン名を表示** - キーを割り当て、押すとメニューを開かずに現在のシーン名が見られます。
- **ホットキーを解除** - 割り当てを外します。
- **診断ログ** - Papyrus ログへどれだけ書くか。通常プレイは **オフ** のまま。バグ報告時は **イベント**。タイミング問題を追うときだけ **毎回**、その後オフに戻してください。パフォーマンスに影響することがあり、とくに **毎回** で顕著です。

  ログが機能するのは、ゲームが Papyrus ログを書いているときだけです。`Documents\My Games\Skyrim Special Edition\` の `Skyrim.ini` または `SkyrimCustom.ini` を編集してください：

  ```
  [Papyrus]
  bEnableLogging=1
  bEnableTrace=1
  ```

  再起動してください。ログファイル：`Documents\My Games\Skyrim Special Edition\Logs\Script\Papyrus.0.log`。`fth_IJW` を検索します。

## 診断

- **Editor ID 読み込み済み** - インジケーターです。点灯時は **シーン** ページと所属クエストに名前、消灯時は ID 番号。**Form ID** はどちらでも生の `0x…` のままです。

- **監視** - 背景チェックが動いているか：
  - **稼働中** - 問題なし
  - **起動中** - リロード直後は普通
  - **遅延** - まだ動いているが、確認がいつもより遅い（忙しいゲーム）
  - **オフ** - **確認間隔** を 0 にした
  - **休止中** - **設定** で **有効** がオフ

- **前回の自己修復** - MOD はときどき自分の帳簿を直します（多くはリロード後）。ここに一行あるのは普通です。

- **バージョン**

## トラブルシューティング

### シーンが名前ではなく ID 番号で表示される

po3 Tweaks が Editor ID を読み込んでいません。`po3_Tweaks.ini` で `Load EditorIDs = true` に設定し、Skyrim を再起動してください。**診断** ページの **Editor ID 読み込み済み** ランプで確認できます。Mod マネージャはデプロイや更新でそのファイルを上書きすることがあるので、`Data` に置いただけのファイルではなく、Tweaks MOD *内*のコピー（または勝つ小さな override MOD）を編集してください：

- **MO2：** 左ペインの Tweaks MOD フォルダ、または Overwrite／優先度の高い MOD。
- **Vortex：** Tweaks の staging フォルダ、または override MOD。更新のたびに再確認してください。

**Form ID** はどちらの場合でも表示されるので、完全に手がかりを失うことはありません。

### 通知が違う言語で出る

隅の通知は、ゲームの言語でも、どのメニュー翻訳ファイルを入れているかでもなく、**設定 > 通知の言語** に従います。英語が既定であり、フォールバックです。

既定のメニュー言語を設定する通常のインストーラ実行は、このコントロールも初期設定するので、メニューと通知が一致します。メニューファイルを手作業で入れ替えただけの場合や、そのインストーラ手順を再実行せずにアップグレードした場合は、**通知の言語** を一度メニューに合わせて設定してください。

### メニューが違う言語で出る

MCM メニューは、上の通知の言語ではなく、ゲームの言語設定に従います。Skyrim はゲームの言語に合う翻訳ファイルを読み込むので、別の言語を入れていても英語のゲームでは英語のメニューが表示されます。変える方法は 2 つあります：

- **インストーラ：** ステップ 1 で言語にチェックし、ステップ 2 でそれを既定のメニュー言語に選びます。これは英語のメニューファイルを上書きし（英語の `.bak` を残します）、**さらに** **通知の言語** も一致するよう初期設定します。
- **手作業：** `Interface\Translations\fth_ItJustWorks_<LANGUAGE>.txt` を `fth_ItJustWorks_ENGLISH.txt` に改名し、英語ファイルを置き換えます。これは **通知の言語** を変更 **しません** - **設定** で一致させてください。さもないと通知は英語のままです。

### メニューや通知が文字化けして読めない

文字は正しく、ただゲームにそれらの文字を描けるフォントがないため、文字化けとして表示されます。Skyrim の標準フォントはラテン文字と西欧の文字はカバーしますが、キリル文字、中国語、日本語、一部の中欧の記号はカバーしません。それらの言語でメニューや通知を使っているなら、それらを含むフォント MOD を導入してください。英語以外の環境ならたいてい既に入っています。入っていなければ、Nexus であなたの言語をカバーするフォントを探してください - [Unicode Font](https://www.nexusmods.com/skyrimspecialedition/mods/103346) が幅広い出発点になります。

### 通知が一度も出ない

まず **診断** ページの **監視** 状態を、次に **監視** のダイヤルを確認してください：

- 状態 **休止中** - MOD がオフです。**有効**（**設定**）をオンにしてください。
- 状態 **オフ** - **確認間隔** が 0 です。10〜240 秒に戻してください。
- **警告するまでの時間** が **0** - それは通知を無効にします。好きな分数を設定してください。

通知は **警告するまでの時間** と同じ時間の数え方をするため、通知が来なくても **シーン内の時間** が高く表示されることがあります - それは正常です。これは実時間で、リロードでリセットされます。通知がなくても、メニューは常に現在のシーンと、そこにどれくらいいるかを表示します。

### シーンを停止したのにシーンが消えない

停止が効かなかったことは一度もありません - 10 年以上にわたってセーブの詰まりを解いてきて、最初は粗い一回限りの版で、いまはこれで、一度もです。ですから、もしシーンが終わらなかったと報告されたなら、あなたは MOD のバグを見つけたか、本当に新しい何かを見つけたということです。それはわくわくすることです。驚きこそ学びが起きる場所です。完全なログがそれを突き止める一番の手がかりです。Papyrus ログをオンにし、**診断ログ** を **毎回** に設定して、ロードオーダー全体で見つかるログやデバッグのオプションをすべてオンにしてください - もう一度起きたときに、捕まえられるように。そのうえで、完全な `Papyrus.0.log` をバグ報告として送ってください。その間は、詰まる前からリロードして遊び続けてください。

### バグ報告、または助けを求める

バグの場合は、**診断ログ** を **イベント** にし、問題を再現してから終了してください。Papyrus ログをオンにしたうえで（`Skyrim.ini` の行は **設定** にあります）、`Documents\My Games\Skyrim Special Edition\Logs\Script\Papyrus.0.log` を開き、`fth_IJW` を検索します。それと、シーンの **Form ID** と **所属クエスト**、そして詰まったときに何をしていたかを添えてください。

送り先：

- **バグ報告：** MOD ページの [Bugs tab](https://www.nexusmods.com/skyrimspecialedition/mods/185927?tab=bugs)、または [GitHub Issues](https://github.com/ryangubele/ItJustWorks/issues)。
- **質問や一般的な手助け：** MOD ページの [Posts tab](https://www.nexusmods.com/skyrimspecialedition/mods/185927?tab=posts)。

## アンインストール

**完全に外す：**

1. **設定** ページで **有効** をオフにする。
2. セーブして、デスクトップへ終了する。
3. マネージャで MOD を外す（または手作業で）。

プレイ途中で外しても安全です。Skyrim は他のスクリプト付き MOD と同じく、セーブに小さな不活性のスクリプト stub を残すことがありますが、ゲームはそれを無視します。任意：セーブクリーナー（例：FallrimTools の **[ReSaver](https://www.nexusmods.com/skyrimspecialedition/mods/5031)**）で、外したあとに stub を消せます - クリーナーは、本当に外したいものにだけ慎重に使ってください。*他の* MOD のゴミを掃除しているあいだ、この MOD は入れたままで構いません。
