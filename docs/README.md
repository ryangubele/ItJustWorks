## Runtime shape

An ESL-flagged plugin with a single `QUST` (master: `Skyrim.esm`), generated by Mutagen — no Creation Kit authoring. Three Papyrus scripts ride the quest's VMAD after build:

- **`fth_IJW_Watcher`** — poll loop, scene state, alert, hotkey, enable/disable, Stop. State persists in the save (bounded: current scene, timers, history ring, flags).
- **`fth_IJW_MCM`** — MCM Helper glue: push ModSettings into the watcher, publish readout, wire buttons. Same quest as the watcher (`Self as fth_IJW_Watcher`).
- **`fth_IJW_Toasts`** — generated at build from the translation tables (not hand-edited). Lookup by notification-language index for `Debug.Notification` strings.

The menu is data under `mcm/Config/fth_ItJustWorks/`:

- **`config.json`** — five pages: Scene, Watchdog, Settings, Diagnostics, Uninstall. Settings holds Enabled, Levity, Notification language, hotkey, diagnostics log.
- **`settings.ini`** — author defaults (Config). Player overrides live in `MCM/Settings/` and only appear for keys that left default.

Labels: `interface/translations/*.txt` (UTF-16 LE, ten languages). Corner notifications use `$fth_IJW_Toast_*` keys baked into `fth_IJW_Toasts`; the MCM enum `iToastLang:Control` must stay in lockstep with bake `$langOrder` (the build asserts that). FOMOD default-menu options seed Config `iToastLang` to match.

## Settings model

**Disk is the source of truth** (MCM Helper ModSettings). Config `settings.ini` supplies defaults (including FOMOD-seeded notification language). User `MCM/Settings/` holds only overrides. The watcher mirrors values in memory; the MCM pushes on `OnConfigInit` / open / change. IDs use `key:Section` form matching `[Section]` blocks.

## Build pipeline

`build.ps1`: generate ESP → bake + compile Papyrus → scrub `.pex` identity (and replace non-ASCII notification placeholders with real UTF-8) → fail if placeholders remain → assemble Data tree → FOMOD + metadata → verify (version, FOMOD refs, notification-language enum order, translation parity, no stray backup files under folder sources) → zip.

Full options: [BUILDING.md](BUILDING.md).

`PexScrub` strips the building machine's username/hostname from `.pex` headers and pins compile time to a stable epoch from the build script.

## Runtime dependencies

To run (not to build): **SKSE64**, **MCM Helper**, **powerofthree's Papyrus Extender**, and **powerofthree's Tweaks** with `Load EditorIDs = true` in `po3_Tweaks.ini` (soft but recommended — names instead of bare form IDs). Optional font mod for non-Latin scripts.

## Rules before you change things

- **`IsPlaying()` is not a stuck-detector** — it stays true for stuck scenes. It only gates out already-ended scenes; **duration** past the threshold is the signal.
- **Alias-free on purpose** — nothing force-persisted to the player, so removal stays clean. Cost: no `OnPlayerLoadGame` on a quest script; the loop re-registers each tick and the MCM re-asserts timer + hotkey on open. Don't add a `ReferenceAlias` to dodge that.
- **ESL range** — every FormID stays in `0x800–0xFFF`. The Builder fails if Mutagen allocates outside it.
- **Notification language index** — bake `$langOrder`, MCM enum options, and FOMOD seeds are one ordered list (`iToastLang` in Config). Reorder one without the others and the build should fail; don't bypass that.
